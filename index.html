VanillaDatabase — High-Performance SQLite Cloud Platform

Nền tảng SQLite Cloud đa người dùng với mã hóa AES-256-GCM data-at-rest, chế độ Write-Ahead Logging (WAL), phân quyền RBAC đa cấp, sao lưu tự động và API REST realtime tốc độ cao cho ứng dụng đa tenant và AI agent.

Kiến Trúc & Tính Năng Cốt Lõi

  • Mã hóa AES-256-GCM: Toàn bộ cơ sở dữ liệu và bản sao lưu được mã hóa ở mức phần cứng, bảo vệ tuyệt đối dữ liệu tenant.
  • Write-Ahead Logging (WAL): Tối ưu hóa ghi đồng thời với độ trễ microsecond, không lo ngại khóa bảng.
  • Cluster Sharding & Gateway Proxy: Cụm phân tán với Gateway định tuyến trong suốt và cơ chế chuyển đổi dữ liệu không gián đoạn (Zero Data-Loss Migration).
  • Bảo mật RBAC & TOTP 2FA: Phân quyền chặt chẽ theo vai trò (Owner, Admin, Editor, Viewer) và chống tấn công phát lại mã 2FA (RFC 6238).
  • Session Revocation (VDB-SEC-01): Cơ chế vô hiệu hóa phiên tức thì qua token version khi đổi mật khẩu.

TypeScript SDK & REST APIs

import { VanillaClient } from '@vanilladb/sdk';

const vdb = new VanillaClient({
  apiKey: process.env.VDB_API_KEY,
});

// Khởi tạo cơ sở dữ liệu mã hóa riêng biệt cho mỗi tenant
const db = await vdb.databases.create({
  name: 'tenant-enterprise-01',
  encryption: 'aes-256-gcm',
  wal: true,
});

console.log(`Database sẵn sàng: ${db.id}`);
